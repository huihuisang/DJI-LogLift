# LogLift 隐私政策

生效日期：2026 年 11 月 3 日

[English](../PRIVACY.md) · [日本語](ja.md) · [한국어](ko.md)

LogLift 由 huihuisang 发布。本政策适用于原生 macOS 应用 LogLift for DJI 及其 Finder 扩展。

## 本地视频处理

LogLift 在你的 Mac 上读取并转换所选视频，不会将视频、音频、文件名或媒体元数据上传给开发者。使用应用无需账号。应用不会向开发者发送分析数据或会话录制，也不会跨应用或网站追踪你。

## 设置与文件访问

应用在 Mac 本地保存偏好设置和文件访问书签，包括相机顺序、导出设置、输出文件夹及你批准用于 Finder 导入的文件夹。应用通过你在 macOS 中授予的权限访问文件，不会请求整个磁盘的访问权限。

你可以在系统设置中关闭通知和 Finder 扩展。关闭应用后，可以从应用的本地容器中移除已保存的偏好设置和文件访问书签。移除这些记录后，应用会在需要时重新请求访问权限。

## 文件保留

原始视频保留在原来的位置。已完成的导出视频保留在你选择的文件夹中，直到你自行删除。从队列中移除视频不会删除原片或已完成的导出。转换失败或取消时，应用会在能够完成清理的情况下删除临时输出。如果强制退出应用或系统终止应用，导出文件夹中可能保留未完成的文件。

开发者不会持有你所选视频或本地偏好设置的副本。如果不再需要，位于应用容器之外的文件，包括已完成的导出视频，需要单独删除。

## 外部链接与支持

应用中的网站链接和隐私链接会打开浏览器。目标网站会按其自身的隐私政策处理网络请求。本政策托管于 GitHub；访问该网站适用 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。开发者网站有其自身的隐私处理方式。

如需支持或咨询隐私问题，可在 [LogLift 项目](https://github.com/huihuisang/DJI-LogLift/issues)中提交问题。通过 GitHub 发送的信息由 GitHub 处理，问题可能公开，因此请勿发布私人视频、个人资料或凭据。应用不会代你发送支持请求或附加视频。

## 政策更新

如果应用的数据处理方式发生变化，本政策及生效日期会随之更新，并按要求更新 App Store 隐私回答。
