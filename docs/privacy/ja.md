# LogLift プライバシーポリシー

施行日：2026 年 11 月 3 日

[English](../PRIVACY.md) · [简体中文](zh-Hans.md) · [한국어](ko.md)

LogLift の公開者は huihuisang です。本ポリシーは、ネイティブ macOS アプリ LogLift for DJI と、その Finder 拡張機能に適用されます。

## ローカルでの動画処理

LogLift は選択した動画を Mac 上で読み込み、変換します。動画、音声、ファイル名、メディアのメタデータを開発者にアップロードしません。アカウントは不要です。分析データやセッション記録を開発者に送信せず、アプリやウェブサイトを横断する追跡も行いません。

## 設定とファイルへのアクセス

カメラの順序、書き出し設定、出力フォルダ、Finder 読み込みで許可したフォルダなどの設定と、ファイルアクセスのブックマークを Mac 上に保存します。macOS で許可された範囲でファイルにアクセスし、ディスク全体へのアクセスは要求しません。

通知と Finder 拡張機能はシステム設定で無効にできます。アプリを終了後、ローカルのアプリコンテナから設定とアクセスのブックマークを削除できます。削除後、必要な場合には再度アクセスを要求します。

## ファイルの保存期間

元の動画は元の場所に残ります。書き出した動画は、削除するまで選択したフォルダに残ります。キューから削除しても、元の動画や書き出し済みの動画は削除しません。変換に失敗した場合やキャンセルした場合は、処理を完了できる範囲で一時出力を削除します。強制終了やシステムによる終了後には、出力フォルダに未完成のファイルが残る場合があります。

開発者は、選択した動画やローカル設定のコピーを保有しません。アプリコンテナ外のファイルや書き出した動画が不要になった場合は、別途削除してください。

## 外部リンクとサポート

アプリ内のウェブサイトとプライバシーのリンクはブラウザで開きます。リンク先は各サイトのポリシーに従って通信を処理します。本ポリシーは GitHub に公開されており、閲覧には [GitHub のプライバシー声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)が適用されます。開発者のウェブサイトには独自のプライバシーの取り扱いがあります。

サポートやプライバシーに関する質問は、[LogLift プロジェクト](https://github.com/huihuisang/DJI-LogLift/issues)で Issue を作成してください。GitHub を通じて送信した情報は GitHub が処理します。Issue は公開される場合があるため、非公開動画、個人情報、認証情報を投稿しないでください。アプリが代わりに問い合わせを送信したり、動画を添付したりすることはありません。

## ポリシーの変更

データの取り扱いが変わる場合は、本ポリシーと施行日を更新し、必要に応じて App Store のプライバシー回答も更新します。
